# DSH 灵动岛显示与交互规格 v5

2026-10-29，用户确认后实现。原生 SwiftUI/AppKit，刘海锚定。

## 尺寸与样式

- 展开宽392pt；纵向硬上限178pt，包含顶部刘海安全区。内容少可缩短，内容多只在内部滚动。
- 两侧内边距14pt；普通任务行28pt；顶部内容栏22pt；审批底栏34pt，按钮26pt高。
- 原生系统字体：任务/来源13pt，审批正文12pt，辅助文字11.5pt；不为容纳长正文而进一步缩小字体。
- 纯黑底，运行绿、审批暖橙；底部圆角16pt，常驻态12pt；约260ms低回弹动画。

## 审批独占规则

只要有待处理审批/提问，整个岛只显示待交互信息：

- 展开态仅显示来源、审批队列、完整正文及操作；不显示运行任务行、运行计数或完成提示，也没有绕过该规则的“返回任务”入口。
- 常驻态仅显示橙色待审批数量；隐藏绿色运行计数。
- 审批全部处理后，恢复运行任务信息。自动展开的审批面板收回常驻态。

## 全文阅读和操作

- 同一岛体内部滚动完整正文，无两行截断；保留宿主发来的reason/displayReason，完全相同的内容去重，移除已确认不需要展示的协议前缀。
- 按钮固定在底部，正文不会覆盖或将按钮滚走。“拒绝/同意一次”与原审批动词一致。
- 复制按钮复制全文；提问显示问题及选项，使用“在 DSH 回答”，不把提问作为工具权限批准。
- 多条审批逐条查看；新请求加入时不切走正在阅读的条目。宿主现有投影每个会话提供当前一条，处理后后续请求继续出现。
- 提交后显示反馈、阻止重复点击；以宿主状态更新移除已处理请求。4秒未确认时允许重试。

## 任务模式

无待交互时显示紧凑单行任务，长标题省略并提供原生悬停全文；超出高度时滚动。挂起/收起时收到完成事件，在同一岛体内显示单行“任务名 已完成”：内容条高24pt，另保留刘海安全区；3秒后恢复常驻或空闲隐藏。连续完成仅更新这一条提示，不叠加窗口。审批期间隐藏完成提示。

## 打开与收起

- 点常驻区展开，点顶部收起按钮或岛外收起。
- 同一审批的状态刷新尊重手动收起，新审批可再次展开提醒。
- 全局/本地鼠标监听以及透明区域点击穿透保持启用，无全屏捕获层。
- 点击运行任务整行、审批来源标题或“在 DSH 回答”，唤醒 DSH 并打开该项对应的对话，然后收起岛。
- 审批标题的导航点击与“拒绝/同意一次”分开，打开对话不产生审批裁决。
- 原生岛发送具体 sessionId；桌面客户端调用 uiWorkspace.openSession，收到会话选择结果后确认。快速连续点击以最新目标为准，未接收命令15秒过期。
- 导航使用 DSH 已有的同源、已鉴权 OWNER Fetch 通道；不注册公网入口或另开端口。
- 关闭宿主输入或收到shutdown后退出；临时窗口和监视器随生命周期释放。

## 动态高度与进程唯一性

- 普通任务随实际行数收紧：当前安全区38pt时，1项96pt、2项124pt、3项152pt，更多内容最高178pt并滚动。
- 短审批正文按测量高度收紧，不保留额外的40pt最小正文空白；长审批仍在既有178pt内滚动。
- 所有展示状态复用同一个NSPanel；内容分支互斥，切换时不保留重叠的旧内容过渡。
- 宿主仅管理一个helper；重复启动/重启请求合并，旧进程退出后才拉起替代者，旧进程的迟到事件不影响新进程。
- 异步标题查询带版本校验，过期查询不得重放已结束任务，也不得污染完成边沿记录。
